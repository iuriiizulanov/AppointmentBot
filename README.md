# Telegram-бот записи на события

Бот на Python 3 использует SQLite и `python-telegram-bot`. Суперадминистратор
создаёт событие и назначает администратора; код события состоит ровно из
10 цифр. Участники присоединяются по коду, выбирают свободное окно и отправляют
запрос. Администратор подтверждает запрос или отказывает с сообщением.

## Запуск

Требуется Python 3.9 или новее. Секреты можно хранить в `.env` в корне
проекта — бот загрузит этот файл автоматически. Например:

```dotenv
BOT_TOKEN=токен_от_BotFather
SUPERADMIN_TELEGRAM_ID=ваш_числовой_Telegram_ID
DATABASE_PATH=appointments.sqlite3
```

Файл `.env` не добавляйте в Git: он содержит токен бота.

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
py bot.py
```

Необязательная переменная `DATABASE_PATH` задаёт путь к SQLite-файлу.
По умолчанию используется `appointments.sqlite3` в текущем каталоге.
Время окон вводится и показывается в локальном времени, которое согласуют
участники; бот не выполняет преобразование часовых поясов.
Администратор должен хотя бы один раз открыть чат с ботом командой `/start`,
чтобы бот мог отправлять ему уведомления.

## Команды

В меню бота можно нажать команду. `/join` запрашивает код один раз и запоминает
событие в SQLite. Дальнейшие действия используют выбранное событие без повторного
ввода кода; если событий несколько, нужное можно выбрать кнопкой. `/leave`
покидает событие и убирает его кнопки действий. Для возврата используйте `/join`.
При нескольких событиях `/switch` меняет выбранное событие.
Кнопки администратора доступны только для событий, в которые администратор
вступил; назначенный администратор должен сначала присоединиться по коду события.
Подписи кнопок в меню русские и описывают действие. Если пользователь не вошёл
в событие или для него нет активного события, событийные кнопки меню не
показываются; `/start` обновляет меню. Доступ также проверяется при нажатии
старых inline-кнопок, поэтому выход из события сразу отзывает доступ.

- `/start` — краткая справка.
- `/create_event <telegram_id_администратора> <название>` — создать событие
  (только суперадминистратор).
- `/join <10-значный_код>` — присоединиться к событию.
- `/leave` — выйти из текущего события или выбрать событие для выхода.
- `/switch` — выбрать другое активное событие, если вы состоите в нескольких.
- `/slots <код>` — посмотреть свободные окна и отправить запрос на запись.
- `/my_bookings` — посмотреть свои окна в активном событии: ожидающие помечены
  как «Запрошено», одобренные — как «Запланировано».
- `/addslot <код> <YYYY-MM-DD HH:MM>` — добавить окно (администратор события
  или суперадминистратор). При использовании кнопки откроется inline-календарь:
  выберите дату, час и минуты (00, 15, 30 или 45). Ввод команды с датой и временем
  также поддерживается.
- `/event_slots <код>` — посмотреть свободные и занятые окна.
- `/requests <код>` — посмотреть запросы и подтвердить или отклонить их.
- `/reject <номер_запроса> <сообщение>` — отклонить запрос с ответом пользователю.
- `/cancel` — отменить текущий пошаговый ввод.

При выборе кнопки «Отказать» бот подсказывает команду `/reject`. Для каждого
окна допускается один ожидающий запрос; после отказа участник может отправить
новый запрос на это окно.
